# Datos

Coloca en esta carpeta los datasets necesarios para ejecutar el laboratorio.

**Reglas Importantes:**
- Puedes subir archivos pequeños si están permitidos por el curso.
- **NUNCA** subas datos sensibles o pesados (gigabytes) al repositorio.
- Si los datos no se pueden subir, deja aquí instrucciones exactas de cómo descargarlos y dónde ubicarlos para que el código funcione.
