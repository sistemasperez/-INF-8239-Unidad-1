# Skills Disponibles

Aquí tienes una lista de los skills (habilidades) personalizados que tienes disponibles y que puedes invocar cuando los necesites en tus tareas y proyectos.

## 1. Adaptar Laboratorio de Datos
*   **Nombre del Skill:** `adaptar-laboratorio-datos`
*   **Cuándo usarlo:** Invócalo cuando vayas a iniciar una nueva tarea del laboratorio y necesites estructurar el proyecto (crear carpetas como `notebooks/`, `data/`, `results/`, etc.) o cuando quieras que te guíe para adaptar o realizar cambios a tu experimento base.
*   **Cómo invocarlo:** Puedes decirme algo como:
    *   *"Quiero adaptar el laboratorio base"*
    *   *"Inicia el skill adaptar-laboratorio-datos"*
    *   *"Ayúdame a estructurar mi repositorio y adaptar mi experimento"*
*   **Qué hace:** Me instruye para no hacer modificaciones de código a ciegas. En cambio, te preguntaré cuál es tu experimento base, qué hipótesis o parámetro deseas cambiar y por qué. Luego te ayudaré a implementar el cambio, comparar métricas y generar las conclusiones.
